# Raritan Watershed Delineation

A GIS-based watershed delineation exercise for the **Raritan River region, New Jersey**, using QGIS and GRASS GIS.

## Watershed Map

![Raritan Watershed](watershed_map.png)

## Methodology

The watershed was delineated using terrain-based hydrologic analysis:

1. DEM preparation and sink filling
2. Flow direction and accumulation analysis
3. Drainage network extraction
4. Outlet selection and watershed delineation

## Tools

- QGIS
- GRASS GIS
- Digital Elevation Model (DEM)

## Outputs

- Delineated watershed boundary
- Extracted drainage network
- Watershed outlet
- QGIS project and final map

**Note:** The delineated area represents the upstream contributing area for the selected outlet, not necessarily the entire Raritan River watershed.
